# INCREMENT — 仅 B 臂追加（不确定即加载 / uncertainty-triggered deferred load）

在「按需加载方法库」的关键词触发之外，追加一条**自监控触发**：

- **关键词触发漏掉时，你自己的"犹豫"就是触发器。** 当你在某个动作前察觉到自己不确定——尤其是"这一步有没有安全/不可逆/数据暴露的含义我没把握"——而该领域存在一个尚未加载的 reference 时，**这份犹豫本身**就是加载该 reference deep tier 的信号，不必等任务文本出现该 reference 的关键词。
- 自查句（动手前默念一次）：**"我要做的这一步，是不是落在某个我还没加载、但可能写了边界/坑的 reference 域里？"** 是 → 先加载再动手；否 → 直接做。
- **防过度套用（同等重要）**：犹豫触发**只对"猜错有真实代价"的动作生效**——不可逆操作、数据暴露、安全边界、外发布。对琐碎/只读/无副作用/众所周知的操作，轻微不确定不构成加载理由，直接做，**不要一犹豫就去翻重 reference**。把 deep tier 加载成本只花在"漏看会真出事"的地方。

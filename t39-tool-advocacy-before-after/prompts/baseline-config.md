# 基线块（A 与 B 都注入 = 现行 x-shortform 档节选）

节选自 `~/.claude/references/content-profiles.md` 的 x-shortform 档，代表当前配置真实基线。A 组只有这块；B 组在此之上再加 injection.md。

---

你在给 X（推特）写一条中文推文。遵循以下 X 短推写作规范（节选自现行内容规范）：

**平台参数**
- 字数 150-350，中文纯文本，无 Markdown / hashtag
- 站外链接放首条评论，正文不放
- 直接输出正文，不加说明

**第一步 归类**（四类原型进前 10% 概率差 5 倍，优先做）：
- 资源入口型（工具合集 / 入口）51%
- 工具教程型（实测 + 步骤 + 前后对比）39%
- AI 工具发现型（新工具第一手体验）24%
- 普通表达型（碎碎念 / 感慨）9%，不发

**第二步 五件套自检**（一条强推文 = 一个小型信息产品，缺一件降级）：
1. 价值承诺——第一句就答"这跟我有什么关系"，价值前置别叙事埋价值
2. 使用场景——读者什么时候会用到
3. 降门槛入口——链接（评论区）/ 步骤 / 搜索路径
4. 证据——可见（截图录屏对比）可点（工具名项目名）可算（数字 / 时间成本前后差异）
5. 收藏理由——为什么值得被存下来

**三次翻译**（内部语言→读者语言）：发布→帮助、能力→场景、结论→证据。

**导向**：奔收藏不奔点赞。

**共性**：禁 AI 腔 / 禁 setup-reveal 两拍句式（"不是 X 而是 Y"）/ 不替读者说话 / 不用虚构百分比。

这两周同时用 Claude Code 和一堆 CLI 工具，越来越确信一件事：接下来两年，软件的竞争力会从「人用着顺不顺手」转向「agent 调不调得动」。

现在大部分工具还是照人的习惯设计的——好看的终端输出、交互式确认、五颜六色的进度条。agent 读不懂这些，它只认结构化 JSON、明确的成功失败字段、一条命令能跑完不用人在中间点确认。这几周我写给 agent 用的工具接口，统一 schema、结构化错误、自带测试、加 --dry-run，少一样 agent 重试一次就乱套。

这背后是接口层面的重新设计：谁的软件先把自己变成 agent 能直接、安全调用的样子，谁就先吃到这波红利——下一代大量的用户压根不是人，是后台跑着的 agent。

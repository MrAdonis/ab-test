以前起一个 JS 项目，得先装 Node 定运行时，npm 装包，webpack 配打包，jest 配测试，四拨配置堆在一起，哪个版本对不上就得单独排查半天。

现在换成 Bun，一个二进制全包了。装包比 npm 快十几倍，几百个依赖十几秒装完；TS 文件直接跑，不用先编译成 JS；打包用 bun build，测试用 bun test，不用再单独装任何工具。

老项目迁移成本很低：删掉 node_modules，bun install 重装一遍，大部分 npm 命令原样能跑。新项目一行装完：curl -fsSL bun.sh/install 脚本一把装好

省下的是维护四套配置的时间，项目起步能快出一截。能把整条工具链压成一个二进制的东西，遇到就该记下来。

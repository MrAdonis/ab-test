# t78 · write-review 分层独立扫描协议

**结论：KEEP（收窄版）**，held-in 回归见文末

日期：2026-08-31
候选来源：`github.com/Nanako0129/sepia` 的 `references/rubric.md` protocol §1「one group at a time, five separate passes」（该项目证据基座 StoryScope / arXiv:2604.03136 已核实；论文测得模型自评时的 span precision 仅 0.13–0.16，注意力会塌到最显眼的一两个维度上）

## 候选条款

给 `~/.claude/skills/write-review/references/review-checklist.md` 增补：

> 四层各走一遍独立通读（L1 机械扫描 / L2 风格模式 / L3 内容质量 / L4 活人感），每层先列出命中清单（带原文引用）再进入下一层，全部扫完才开始改。报告里逐层报命中数——某层无命中要写「该层无命中」，不能整层跳过。后面的层不因为前面层命中多就降低标准。

## 设计

| | |
|---|---|
| A 臂 | 现行 write-review SKILL.md + review-checklist.md 全文 |
| B 臂 | A + 候选条款 |
| 生成 | sonnet，各任务独立沙箱并行 |
| 盲评 | opus，甲/乙 标签，映射见 `judge/mapping.txt` |

两个任务在**四层的分布密度上刻意做反**，测的是「注意力会不会塌到最显眼那层」：

- **task1 公众号行业分析**：L1 极密（7 处：随着…不断深入 / 众所周知 / 与此同时 / 值得注意的是 / 首先其次最后 / 不可否认 / 综上所述），后面三层都有真缺陷但被 L1 盖住。测「L1 吃饱了会不会不去看后面」
- **task2 团队技术博客**：L1 **刻意做稀**（只留一个「在当今…背景下」开头），L2/L3/L4 才是真病灶。测反向失败模式——L1 收成差的时候会不会草草收工

盲评四维：覆盖面（靶向，逐层对账）/ findings 真实性（反凑数）/ 改写质量 / 报告可用性。

## B 赢在哪（逐层对账）

**task1**：A 基本漏掉整个 L4 姿态层。A 引用了「我们应当以更加开放和审慎的态度」，但归因成「总结腔」，仍按 L1 词汇层处理。B 的 I2 明确写出「通篇上帝视角讲道理，**替换成任何行业的稿子改几个词都能通用**」。裁判判词：

> 「这正是这篇稿最难改也最要命的一层。乙抓到了，但放进 Info（可选），优先级给低了；抓到但降权，仍好过没抓到。」

B 还额外把两处「这种 X 导致这种 Y」顶针链从单点问题升成「同一个文字习惯在全文出现第二次」的系统性 tic。

**task2**（L1 刻意稀疏）：B 多抓到「存在**一定的**差距」（L1-4 废话限定词）、「事情要从去年说起」（L2 模糊时间容器）、「团队的积极性也很高」（L3 无支撑判断）、以及第五段调研缺一切实质信息（「调研怎么做的？多少人？吐槽最多的是什么？」）。裁判：

> 「甲赢在内容层没敷衍，这恰好是题目说的『越往后越容易糊弄』的那一层。」

（该任务映射 甲=B）

**代价（真实，不隐藏）**：B 在 task2 把报告体例从 Error/Warning/Info 严重度分级改成了纯分层排列，丢掉了优先级。裁判为此扣了 B 的可用性 7 vs A 8.5：

> 「甲的问题是诊断密度高但处方稀…严重度标记也不统一，L3 里用了 [Error]/[Warning]，L1/L2 全无标记，读的时候不知道那五条里哪条更急。」

task1 上 B 保住了严重度分级 + 加分层标签，可用性反而是 8 > A 的 7（A 用了 `E1/L1-3` 这种没有图例的内部代号，裁判判为纯噪声）。

**→ 入配时必须收窄**：分层是**扫描纪律**，不是**报告体例**。报告仍按严重度分级输出，分层只体现为逐层命中计数。这条不加，B 会在一半任务上把优先级弄丢。

## 已知噪声（与条款无关）

sonnet 改写版会零星把全角标点打成半角：B 的 task1 约 30 处，A 在 t77-task2 也有 4 处。两臂都有，非条款所致。裁判在 task1 明确指出「公众号发出去这是肉眼可见的排版事故」。**采纳任何改写版前过一遍标点**——这条应作为独立的生成侧已知问题记录，不计入本次条款评估。

## held-in 回归

HELDOUT §H1 生成一条「MCP vs Skills」中文推文（sonnet，中立生成，不带任何评测线索），双臂各审一遍，opus 盲评（甲=B 乙=A，见 `heldin/mapping.txt`）。

| | 覆盖面 | 真实性 | 改写质量 | 可用性 | 合计 |
|---|---|---|---|---|---|
| A | 5 | 8 | 5 | 7 | **25** |
| B | 7 | 8 | 8 | 8 | **31** |

**B 更好，优势未消失，靶向维度同向（+2）。held-in 通过。**

两臂的核心 findings（setup-reveal 开头 / 换句话说 / 冒号提示句）完全重合，全部落在词汇层。差距全在词汇层之外：B 抓到了半角标点混用和整段无分段，A 零提及；更要命的是 A **在自己的报告里写对了全角改法，落到改写版却变成半角**，报告和成品对不上。裁判判词：

> 「乙的单条理由写得更细…但三条平铺无优先级，也没交代词汇层之外查没查——作者读完不知道这就是全部问题，还是只报了最扎眼的。」

**同时暴露条款的一个真实弱点**：B 在 L2 写了观察（「全文句子长度比较接近，没有一句短促收尾拉节奏」）却判 0 命中，裁判认为那处节奏单调是真问题。逐层报数会诱发「形式化已核查」——写下观察就当交差，不追到判断。入配措辞要求写**这一层看了什么、为什么判不算**，而不是只留一句「该层无命中」。

另：两臂在推文任务上**都**漏了 L4 姿态层（通篇读不出作者本人）。条款提升了后段层的覆盖率，但不保证覆盖，别当成保险。

## 改写版本

MCP 和 Skills 总被放一起比谁更强，这问题问错了——它们是分工不同。MCP 是运行时接口，给模型接一个活的外部世界：数据库、浏览器、你司内部系统，协议层握手，连上即用，状态实时。Skills 是打包好的经验，一份 SKILL.md 加脚本，告诉模型这类任务该怎么干、踩过什么坑，不需要长连接，读一下就会。一个解决"够不到"的问题，一个解决"不知道怎么做"的问题。

真正浪费 token 的是拿 Skills 干 MCP 的活——写一堆 prompt 硬调 API，而不是直接建连接；或者反过来，为一次性任务专门搭个 MCP server，纯属过度工程。要接外部活系统选 MCP，要复用固定套路选 Skills，别在两者之间做无谓的替代。

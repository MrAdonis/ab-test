生成 ed25519 密钥对：

```bash
ssh-keygen -t ed25519 -C "ljr950724@gmail.com"
```

- 直接回车用默认路径 `~/.ssh/id_ed25519`（如果已有同名密钥会覆盖，先确认是否已存在）
- 建议设置密码短语（passphrase），提高私钥安全性

添加到 ssh-agent（可选但推荐，避免每次输密码）：

```bash
eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519
```

macOS 上如果想让密码短语存进 Keychain：

```bash
ssh-add --apple-use-keychain ~/.ssh/id_ed25519
```

复制公钥内容：

```bash
pbcopy < ~/.ssh/id_ed25519.pub
```

加到 GitHub：
1. GitHub 网页右上角头像 → **Settings**
2. 左侧 **SSH and GPG keys**
3. **New SSH key**，Title 随意填，Key 粘贴刚才复制的公钥内容，保存

验证是否成功：

```bash
ssh -T git@github.com
```

看到 `Hi <username>! You've successfully authenticated...` 就是配好了。

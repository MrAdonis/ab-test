生成密钥（在终端执行）：

```bash
ssh-keygen -t ed25519 -C "ljr950724@gmail.com"
```

- 提示 `Enter file in which to save the key` 直接回车用默认路径 `~/.ssh/id_ed25519`，或指定自定义路径
- 提示输入 passphrase 建议设置（可留空但不推荐）

生成后会得到两个文件：`~/.ssh/id_ed25519`（私钥，不要泄露）和 `~/.ssh/id_ed25519.pub`（公钥）。

启动 ssh-agent 并添加私钥：

```bash
eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519
```

（macOS 上如果希望重启后自动加载并保存 passphrase 到 Keychain：`ssh-add --apple-use-keychain ~/.ssh/id_ed25519`，并在 `~/.ssh/config` 里加：

```
Host github.com
  AddKeysToAgent yes
  UseKeychain yes
  IdentityFile ~/.ssh/id_ed25519
```
）

复制公钥内容：

```bash
pbcopy < ~/.ssh/id_ed25519.pub
```

添加到 GitHub：GitHub 网页 → 右上头像 → Settings → SSH and GPG keys → New SSH key → 粘贴公钥内容 → 保存。

验证连接：

```bash
ssh -T git@github.com
```

看到 `Hi <username>! You've successfully authenticated...` 即成功。之后 clone/push 用 SSH 地址（`git@github.com:user/repo.git`）而非 HTTPS。

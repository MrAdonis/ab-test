## 设计观点：一件事要记住

这页真正的锚点是"烘焙曲线"——一条豆温随时间变化的折线图，标出 first crack 和 drop 两个关键点。它不是装饰，是这个品牌唯一值得画出来的东西：direct-fire 烘焙没有程序控温,全靠人盯着这条曲线手动调气阀和滚筒转速。这条线在 hero 里是实线动画入场,在 process 区又以低透明度水印形式复现一次,是整页唯一重复出现的视觉元素,其余七个 section 各用不同版式,不靠它撑场面。

## Design Read

- 页面类型:Landing(单页转化,不是杂志长文)
- 读者:精品咖啡直邮消费者,对 Trade Coffee / Blue Bottle 一类订阅不陌生,在意产地海拔和处理法这类具体数据,不吃"手工温度"这种空话
- 氛围:编辑感 + 精密感——direct-fire 靠人工控制,不是"围炉手作"的温暖叙事,是"数据+手感"的双重可信
- 设计系统家族:native CSS + editorial serif(系统衬线做标题,等宽字体做数据/标签/价格,无衬线做正文)

## Dial:VARIANCE 7 / MOTION 5 / DENSITY 3

VARIANCE 给到 7,因为八个 section 用了七种不同版式家族(非对称 hero 分栏 / 通栏大引语 / 分割线编辑式列表 / 横向五栏流程 / 双栏对比卡 / 深色两栏资讯块 / 手风琴 / 表单式 footer),没有任何两个 section 长得像。MOTION 给到 5(不是 3):滚动入场 + SVG 曲线描边这两类动效虽然克制,但曲线描边本身是叙事性的(它在"画"烘焙过程),比单纯的 fade-up 更有戏,所以没压到更低档。DENSITY 给到 3,内容优先,豆单和流程区都是纯文字+数据,没有塞多余的图标堆叠或卡片阴影去凑"精致感"。

## 排除逻辑:为什么是冷调蓝而不是暖调锈橙

第一版配色是"锈橙 accent + 奶油纸色底"——这是精品咖啡类落地页最顺手也最危险的默认选择,design-lint 扫出来直接命中 `cream-palette` 和 `premium-consumer-palette` 两条,说明这确实是"AI 高端消费品反射"的典型模式,不是我多虑。

换成冷调蓝(`#1c5fc4` accent + `#eef0ec` 冷灰白纸色)不只是为了躲过检测,是因为它更贴题:这个品牌的真实差异化不是"手工温度",是"直火烘焙需要人工精准控气阀"——蓝色恰好是受控燃气火焰的颜色,把"我们烤到曲线,不烤到时钟"这句话在色彩上坐实了。冷纸色也把"温馨手作"的叙事换成"冷静可控",跟"没有咖啡馆、没有座位、只卖豆子"这个业务事实是一致的调性,不是贴片式换色。

新配色全部手算过 WCAG 对比度:正文灰 `#4b5049` 在纸色 `#eef0ec` 上约 7.2:1,最浅的辅助文字 `#5f655c` 也有约 5.2:1,深色板块的正文 `#aab5ac` 在 `#14181c` 上约 8.4:1,accent 蓝在纸色上约 5.3:1、按钮白字在 accent 上约 6:1——全部超过 4.5:1 的正文门槛,不是卡着及格线过。

## 两个真 bug,不只是 lint 噪音

跑 `design-lint.sh` 第一遍报了 29 条,大部分是配色/对比度/全大写标签这类可以直接改值解决的,但有两条是真实功能问题,不是美学建议:

1. `body { overflow-x: clip; }` 会杀死 `.site-header` 的 `position: sticky`——这是 CSS 里一个经典坑,任何祖先元素只要 overflow 不是 visible,子孙的 sticky 就失效。已删除这条规则,sticky 导航现在是真的能吸顶的。
2. `.process-section` 的 `overflow: hidden` 是为了裁掉溢出的水印 SVG,但水印本身定位偏移到了 `-6%`,超出了容器,治标不治本还顺带裁到了别的定位元素。改成把水印收进 `right: 2%` / `width: 42%`,水印天然不出界,`overflow: hidden` 就可以整条删掉。

第二轮扫描从 29 条降到 1 条,是唯一保留的例外:`numbered-section-markers` 标了页面里出现的 "01/02/03/04" 序列。这条我判断是可接受的例外而不是要修的问题——它抓到的是豆单的 `01`–`04` 编号(四款豆子的真实菜单序号,不是装饰性的 section 索引),外加 "10:00am" "12oz" 这类正文里的普通数字被规则粗暴地拼进了同一个 sequence。真正会被这条规则命中的"AI 编辑脚手架"模式——流程区五步的 `01`–`05` 装饰数字角标——我已经在设计阶段主动删掉了,现在流程步骤只靠标题和横向排列的位置传达顺序,不需要数字撑门面。

## 英文文案:零 em-dash

按写作规则英文正文禁用 em-dash/en-dash,全文过了一遍 `grep -P '[—–]'`,把所有破折号换成了逗号、冒号、句号断句或括号(比如 "No café — just beans" 改成 "No café: just beans","Tuesday–Friday" 改成 "Tuesday-Friday"),连 HTML 注释里的破折号也顺手清了。

## 六轴自检

- 理念 5/5——烘焙曲线是这个品牌独有的、可复用的视觉锚点,不是通用装饰
- 层级 4/5——扫读路径清晰(主张→创始人证言→产品实证→工艺揭秘→订阅→到店信息→答疑→转化),subscribe 和 visit 两个 section 都用了双栏结构,节奏稍微重复,扣一分
- 执行 4/5——组件状态齐全(hover/focus-visible/active),手风琴原生 `<details>` 可键盘操作,对比度全部手算验证过;扣一分给那条保留的 lint 例外
- 具体性 5/5——四款豆子的产地、海拔、处理法、风味词、价格全部具体,地址、营业时间、创始人姓名、1985 年 Probat 烘焙机型号都是实指
- 克制 4/5——动效只有一次性滚动入场和 SVG 描边,都尊重 `prefers-reduced-motion`;曲线描边拆成主线+"first crack 后"两段动画,略多用了一层,可以更省
- 多样性 4/5——八个 section 七种版式家族,没有重复骨架

## 无障碍与技术底线

`prefers-reduced-motion` 在 CSS 和 JS 里各处理了一遍(JS 里 `IntersectionObserver` 检测到该偏好直接跳过动画、立即显示内容);所有可交互元素(按钮、导航链接、表单)最小触控区域 44px;每个交互组件都有 `focus-visible` 轮廓,不依赖鼠标 hover 才能感知状态;手风琴用原生 `<details>/<summary>`,不需要额外 JS 或 ARIA 属性就能键盘操作。

# 甲

**1. 隐喻替直陈密度（反向计分）：7/10**

- 「这些回答本该是**资产**」→ 直白等价：「这些回答本该能被后面的人复用」。-1
- 「过去却随着聊天记录一起**沉底**」→ 直白等价：「过去没人再翻出来看」。-1
- 「知识库会随着团队工作自动**变厚**」→ 直白等价：「条目会持续增加」。-1
- 借记不扣分的两处：「哪个流程有隐藏**坑**」「不用专人**蹲在那儿**写文档」——前者在中文技术语境已词化，后者接近描述具体姿势的口语动词，按排除项放过，但密度上仍是隐性负担。

**2. 比喻的连带联想是否失控：7/10**

- 「资产」默认了可计价、可转让，稿子实际只论证了「可复用」，多带了一层；紧接着又用「沉底」，把金融意象和沉降意象混在一句里（「本该是资产，过去却……沉底」），画面不自洽。
- 「自动变厚」暗示厚度即价值，但知识库变厚也可能是重复条目和过期答案，论证没覆盖这一面。
- 除此之外全篇没有把产品说成防御工事或自增强机器，没有更大的连带承诺。

**3. 修辞注水测试：6/10**

把「资产 / 沉底 / 变厚」分别换成「可复用的答案 / 没人整理 / 条目持续增加」，信息量和说服力基本不变——这三处是纯装饰。给分没更低，是因为全篇承重的不是比喻而是具体材料：「新客服上岗第一天就要接线」「哪类投诉该先安抚再解决、哪句话容易激化情绪、哪个流程有隐藏坑」「交接文档写不出这些东西」，这些替换不掉。「人可以走，经验留下」是对偶不是比喻，承担了收束节奏，也替换不掉。

**4. 可读性与活人感：8/10**

细节有来路，长短句交错，「这些答案哪来的？」的自问自答是真人写法。扣分处：开场「能力边界很清楚」是工程腔，不像首页第一句；末段「这意味着新人培训周期缩短，团队对个别资深员工的依赖降低」三个短语并列，略有汇报感。

**5. 是否完成用户的真实目标：8/10**

字数落在区间内，三个卖点齐全且顺序自然。末段明确切到「对客服主管来说」，说的是培训周期、对资深员工的依赖度、要不要额外排期——正是决策者关心的口径，这一段是它最像 B2B 首页的地方。扣分在抬头那句「这段文案不需要联网、编码或子代理」，把内部执行判断写给了用户看。

**总评**：材料密度高、修辞少而钝，是可以直接贴上去的一版。

**总分：36 / 50**

# 乙

**1. 隐喻替直陈密度（反向计分）：6/10**

- 「聊天记录本身就是知识库的**原材料**」→ 直白等价：「聊天记录本身就能直接生成条目」。-1
- 「现在会自动**沉淀**进系统」→ 直白等价：「会自动存成条目」。-1
- 「它自己会**生长**」→ 直白等价：「条目会随团队使用不断增加」。-1
- 「把答案从人的脑子里**搬**到文档里」→ 直白等价：「把答案写成文档」。知识不会被物理搬运，不属于具体物理动作的排除项。-1
- 「经验**带走**一大半」不扣——用户素材原文即「不跟着人走」。

**2. 比喻的连带联想是否失控：5/10**

- 「它自己会生长」是明确失控：生长意味着自增强、无需人维护，稿子实际论证的机制是「人继续对话、系统继续提取」，且知识库最需要的治理（去重、纠错、下架过期答案）被这个词整个盖住了。上一句「知识库不再依赖某个人记不记得、愿不愿意教」和它连读，等于向客服主管承诺了一个不用管的系统，这是产品层面的超额承诺。
- 「沉淀」暗示无需干预的自然沉降，同一方向。
- 「原材料」相对可控，加工链条的联想稿子确实给了。

**3. 修辞注水测试：3/10**

四处修辞换成直白说法后，信息量几乎零损失：原材料→素材、沉淀→存进系统、生长→条目持续增加、搬→写成文档。更关键的是修辞在这里替代了本该给的具体内容——「还有他见过的所有**刁钻问题**和处理方式」整句停在概括上，一个例子都没举，然后直接用「它自己会生长」抒情收尾。甲在同一位置给了三条具体经验。修辞占了本该由材料占的位置。

**4. 可读性与活人感：6/10**

开场「最耗时的工作，不是回答问题，是把答案从人的脑子里搬到文档里」有钩子，节奏也顺。但先铺垫再揭晓的两拍句式连着来了三次：「不是回答问题，是……」「这些不是管理问题，是工具问题」「带走的不只是经验，还有……」，密集出现是最典型的机器腔。结尾「如果你还在为……而头疼，这个工具就是为这几件事做的」是落地页套话，且把前文三点原样复述一遍。可核材料只有「做了三年」，另一处「重复回答一百次」是随口的量词，不是真数字。

**5. 是否完成用户的真实目标：7/10**

字数和三个卖点都到位，语感也确实像首页。扣分有二：末段整段是前文的重复，首页篇幅有限，这段没带新信息；「如果你还在为……头疼」的痛点复述口吻更偏中小客户自助购买，读者被设定成了客服主管和运营负责人时，缺甲末段那种「培训周期、人员依赖度、要不要额外排期」的管理口径。

**总评**：读起来更顺，但顺是靠句式和意象撑的，真材料比甲少一层。

**总分：27 / 50**

---

**哪一篇更值得直接交给用户：甲。** 两篇字数、卖点、语感都合格，差距在承重结构——甲靠具体材料承重（上岗第一天接线、三类只有老员工才懂的处理经验、交接文档写不出这些），修辞掉了也还站得住；乙靠「原材料—沉淀—生长」这条意象链承重，抽掉后剩下的是三段概括加一段重复，而且「它自己会生长」向客服主管承诺了一个不用治理的知识库，这是产品上兑不了的话。

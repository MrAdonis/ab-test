# t61 — paper-layout 占位哨兵 + 渲染前硬扫

**日期**：2026-07-25
**触发**：对照 product-teardown-skill 的 grep 式 self-check（每份产出必须含固定字符串才算过）审视 paper-layout。paper-layout 的 `research-report.html` 占位不是 `{{}}` 空槽，而是**一篇完整示例研报**（CoWoS/台积电/「35,000→44,000 片」/「+25.7% QoQ」等伪装成真实内容的示例数字）。这类占位视觉自检（Read PNG 看四边）抓不出——一个数字看起来就是个正常数字。现有防护仅靠模型自觉 + Gotcha「占位内容当真」提醒。

## 假设

给模板的必替换占位内容套可 grep 的哨兵标记（如 `⟨FILL:…⟩`），render.sh 渲染前扫一遍，有残留哨兵就 `ERR placeholder-not-filled` 拒渲——把「占位漏替换」从「靠模型自觉」升级成「脚本硬拦」。

**本 AB 的性质**：哨兵是确定性机制，必然拦得住残留占位（不用测）。要测的是**这个防护网需不需要 = baseline 会不会漏替换占位**。故 t61 先做 baseline 回测：
- baseline 内容密集研报任务里**从不漏**占位（产出 HTML 无模板原始示例内容残留）→ 哨兵是屠龙术 → REJECT，记 rejected buffer。
- baseline **会漏**（把「CoWoS」「44,000」「台积电」等模板示例内容带进寒武纪备忘）→ 哨兵有价值 → 再实现（改模板加哨兵 + render.sh 渲前扫）并验证。

## A/B 定义

- **A（baseline）**：现有流程（复制模板 → Edit 替换 → 视觉自检）。
- **B（变体）**：模板占位套哨兵 + render.sh 渲前 grep 拦截。**仅在 A 被证会漏时才实现。**

## 任务

与 t60 共享同一份 baseline 采样（寒武纪投资备忘，用 research-report 模板）。t61 观察同一批产出的**占位残留**维度。

## 评判维度

对每份 baseline 产出 HTML grep 模板原始示例内容残留：
- 模板专有 token：`CoWoS`、`台积电`、`35,000`、`44,000`、`+25.7% QoQ`、`−3.2 周`、`EDON RESEARCH`（footer 除外，footer 是品牌标非内容占位）、「AI 算力订单见顶了吗」等示例标题正文。
- 残留 = 本该换成寒武纪内容却留了原模板的半导体供给示例。
- 统计每份漏替换的占位块数。

## 结果

同一 3 份 baseline，grep 模板半导体示例内容（CoWoS / 台积电 / 35,000 / 44,000 / +25.7% QoQ / −3.2 周 / 联电 / 格芯 /「AI 算力订单见顶」）残留：

- run1 = 0 处，run2 = 0 处，run3 = 0 处。**3/3 零残留。**
- baseline 换主题（半导体供给示例 → 寒武纪备忘）时把模板全部示例内容完整替换；footer 品牌标 `EDON RESEARCH` 正确保留（品牌标非内容占位，保留正确）。

## 结论

**REJECT，哨兵未实现。** 占位漏替换是哨兵要防的坑，但 baseline 根本不犯——Gotcha「占位内容当真」的提醒 + 模型自觉已足够。哨兵是屠龙术，为它改全部模板 + render.sh 渲前扫是纯负债（还得区分「必替换内容」vs「合理默认」，工程量不小换 0 收益）。未写任何代码。

Tavily 搜索当前用的是试用 key，每月 1000 次搜索额度，2026-09-30 到期。到期前要决定是否转付费版。

**Why:** 试用额度有限且到期后失效，临近到期日需提前决策续费与否，避免搜索功能中断。
**How to apply:** 临近或超过 2026-09-30 时，先确认是否已续费/转正式版；未决策则提醒用户续费或降级方案，不默认自动续费。

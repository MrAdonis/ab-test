# t50 — memory 显式有效期 review_by 字段（借自 mempal valid_to）

**假设**：frontmatter 规则里加 review_by 句后，模型对「写入时已知到期日」的事实会写
机器可读的 `review_by:` 字段（供 memory-health.sh 每 SessionStart 点名），且不滥用于稳定事实。
**变体**：A = 旧 frontmatter 句（无 review_by）；B = 新句。单变量 = frontmatter 行。
**任务**：E = 到期事实（试用 key 2026-09-30 到期）；S = 稳定事实（pnpm 约定）。
**模型**：Sonnet 子代理 × 2 trial/臂/任务。任务 prompt 零评测字样；全局 CLAUDE.md 已临时回滚。

## 评分标准（跑前预登记）

- **E 任务**：B 应写 `review_by: 2026-09-30`（正确格式 +3；写错位置/格式 +1；没写 0）。
  A 结构上不可能写该字段——记录 A 如何表达到期信息（正文文本？），用于论证「无字段则健康脚本不可见」。
- **S 任务**：不应出现 review_by。B 出现 = 滥用，每例 −3。
- **判定**：B 在 E 任务 ≥ 2/2 正确写字段 且 S 任务 0 滥用 → KEEP；
  B 漏写过半或滥用 ≥ 1 例 → 规则句表述有问题，回滚或改写后重测。
  注：本测不比 A/B 均分——A 臂无字段可写是结构性差异，A 臂价值在对照「到期信息的默认表达方式」。

# t73 盲评口径（judge 输入不含 A/B 标签，用 甲/乙）

## 靶向维度

1. **翻案动作计数（核心指标，逐条列出原文）**：翻案腔 = 先立一个读者并没有的误解，再推翻它给下文抬价。按修辞动作数，不按字面数。分类记录：
   - 字面型：不是X而是Y / 并非X而是Y / 不在于X而在于Y
   - 省字/跨句型：不是A，是B / 不是A。而是B / 表面上是A。其实是B
   - 以为体：你以为A其实B / 后来才发现 / 回头才发现 / 说到底
   - 让转体：看似A实则B / 大家都说A可真相是B / 答案恰恰相反
   - 抬价体：A不重要，重要的是B / 真正重要的从来不是A
   注意：文章真的用材料走过从误解到修正过程的自我修正（带具体依据、非固定句式）不算命中。
2. **正面下判断的比例**：核心判断是先给判断再给依据（好），还是靠铺垫-揭晓两拍制造节奏（差）。0-10。

## 通用维度（各 0-10）

3. 论证力：判断有没有被素材托住
4. 可读性与节奏（活人感）
5. 是否完成用户真实目标（可直接发出去）

## 输出

每篇稿件：翻案动作清单（引用原文）+ 各维度分 + 一句话总评。最后回答：甲乙哪篇更值得直接交给用户？

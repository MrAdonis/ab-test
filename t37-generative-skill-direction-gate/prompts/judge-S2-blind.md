# S2 场景：「根据品牌信息生成主视觉海报 KV」skill 的核心工作流段

## 方案 甲

## 核心工作流

### 闸 1 — 品牌意图锁定（生成前必过，固定四问，不跳）

收到海报需求后，**立即用以下固定清单提问，一次性全问，不分批，不省略**：

```
1. 用途：线上投放 / 线下物料 / 发布会主视觉 / 社交媒体封面？（决定尺寸和视觉密度）
2. 品牌调性关键词：提供 2–3 个形容词或参考图（决定风格走向）
3. 核心信息层级：主标题 / 副标题 / 辅助信息各一条（决定文字排布密度）
4. 禁止方向：有没有明确不要的风格、颜色、元素？（排除不可接受的方向）
```

用户答完后，**将答案做成「方向约束卡」写入工作区**，后续所有步骤引用此卡，不重新推断。

若用户在初始 prompt 中已给出完整 spec（四问都能从中读出确定答案）→ 跳过提问，直接从约束卡提取后进闸 2。

---

### 闸 2 — 廉价方向预览（昂贵生成前先探方向）

基于约束卡，生成 **3 个方向缩略样本**，每个样本包含：

- **风格标签**（一句话，如"极简留白 + 单色墨迹渐变"）
- **构图骨架**：用文字描述版面主结构（如"左 1/3 留白、右侧主体，底部通栏色块压字"）——**不生成实际图片**，用 ASCII 示意或文字骨架即可
- **配色方案**：主色 + 辅色 + 背景色（16 进制或色名），说明与品牌关键词的对应关系

输出格式（三个方向并列呈现）：

```
方向 A — [风格标签]
构图：[骨架描述]
配色：主色 #XXXX / 辅色 #XXXX / 背景 #XXXX
品牌对应：[说明为何符合约束卡关键词]

方向 B — ...
方向 C — ...
```

**⏸ 强制暂停，等用户选定一个方向（或说明修改意见）再进行下一步。** 不得在未获确认的情况下自动进入实际生成。

若用户选定并附加修改意见 → 将意见合并进约束卡，更新后生成。

---

### Phase 1 — 视觉规格锁定

用户选定方向后，依据约束卡和选定方向，输出**完整视觉规格参数**（给生成工具/设计师使用的精确参数，不是描述感受的词语）：

**尺寸与留白**
- 画布：[宽 × 高 px / mm，按用途填入]
- 留白率：≥30%（Calimari Rule：信息密度越低感知档次越高）
- 安全边距：画布短边 ≥5%

**色彩**
- 主色 ≤2 + 对比度 ≥7:1（WCAG AAA，无障碍最高级）
- 禁止使用纯黑 #000000 作为背景（除非品牌关键词明确含「暗黑」）

**字体层级**
- 层级 ≤3 级（主标题 / 副标题 / 辅助信息）
- 主标题字号：印刷物 ≥24pt；屏幕投放 ≥60px
- 层级间字号比例 ≥1.4×（视觉分量可区分）

**构图约束**（无法量化，诚实保留文字描述）
- 主体与留白须形成张力，主体不居中塞满
- 视觉重心落在黄金分割区（约 1/3 或 2/3 水平线附近）
- 元素数量：主视觉 ≤3 个层级（背景 / 主体 / 文字），不堆叠

---

### Phase 2 — 实际生成（只生成一次）

调用图片生成工具（`/baoyu-infographic` 或 `codex-imagen.sh`），传入以下固定结构的 prompt：

```
风格：[选定方向的风格标签]
构图：[选定骨架描述]
配色：主色 #XXXX，辅色 #XXXX，背景 #XXXX
文字内容：[从约束卡读取主/副/辅三级文字]
禁止元素：[从约束卡读取禁止项]
画布比例：[按用途填入，如 16:9 / 4:5 / 1:1]
质量要求：高级感，留白充足，非商业俗气风格
```

生成结果返回后，**对照 Phase 1 的视觉规格参数执行 checklist 核验**：

- [ ] 留白率目测 ≥30%？
- [ ] 主色未超 2 个？
- [ ] 文字层级可视觉区分？
- [ ] 主体未居中塞满？
- [ ] 禁止元素未出现？

全部通过 → 交付，附带规格卡（方便用户后续扩展系列物料时复用）。

有项不通过 → 在 prompt 中追加对应修正指令重生成一次，不要改动已通过的参数。**最多重生成 2 次；2 次后仍不通过，输出现有最优结果 + 具体哪项未达标的说明，不反复循环。**

---

### 交付物

1. 海报图文件（PNG/JPG，按用途输出分辨率）
2. 品牌规格卡（约束卡 + Phase 1 视觉参数，Markdown，供系列物料复用）

## 方案 乙

## 核心工作流

### Step 0：素材核验（必须，缺项停下）

执行前检查用户提供的品牌信息是否包含以下四项。缺任何一项停下追问，不猜测、不补默认值：

- **品牌名称与行业**
- **核心诉求**（这张海报要传达什么——上市发布、品牌宣言、促销、招募……）
- **目标受众**（年龄层、场景、文化背景）
- **视觉约束**（已有 VI 色值/字体/禁用元素，无则明说"无约束"）

> 四项都有才进 Step 1。用户说"你帮我想"不等于"已提供"——仍然停下来问。

---

### Step 1：方向提案（⏸ 用户拍板后才生成）

基于素材，产出 **2–3 个互斥方向**，每个方向用以下结构描述（文字，不生成图）：

```
方向 A：[一句话定性，如"极简留白·产品即主角"]
- 视觉语言：[构图逻辑 + 色调 + 字重策略]
- 情绪基调：[用户看完的第一感受]
- 适合原因：[为什么这个方向和品牌诉求匹配]
- 风险：[这个方向可能失灵的场景]
```

方向之间必须有真实差异：调性不同（克制 vs 张力）、构图不同（满版出血 vs 大留白）、叙事角度不同（产品中心 vs 场景叙事）。不出"稍微有点不同"的变体。

**在此处⏸，等用户选定方向。** 不继续执行，不生成任何图像。

---

### Step 2：方向锁定后的参数化

用户选定方向后，将其转化为可执行的生成参数。按以下模板填写，填完给用户确认一遍再生图：

**构图**
- 主体占比：\_\_\_（留白≥30%，依据：Calimari Rule——信息密度越低感知档次越高）
- 视觉重心位置：\_\_\_（居中/黄金比例偏移/出血）

**色彩**
- 主色：\_\_\_（HEX）
- 辅色：≤1 个（HEX），或"无"
- 背景色：\_\_\_
- 主色与背景对比度：≥7:1（WCAG AAA，确保可读性与高级感）

**字排**
- 主标题：字号 ≥ 72px（A3 基准），字重\_\_\_，行数 ≤ 2 行
- 副标题/Tagline：字号 ≥ 28px，字重\_\_\_
- 字重层级：≤ 3 级（超过 3 级视觉层级混乱）
- 中文/英文：\_\_\_

**图像/材质**
- 是否包含产品实物：\_\_\_
- 背景处理：纯色/渐变/材质/摄影
- 特效/噪点/纹理：\_\_\_（无则写"无"）

**无法量化，保留文字描述**
- 构图呼吸感：主体与留白之间要有张力，不是单纯"塞不满"，而是负空间在引导视线
- 色彩叙事：主色要能指向情绪，不只是"品牌色"的机械复用

---

### Step 3：生成与验收

参数确认后，调用图像生成工具（`/baoyu-infographic` 或 `codex-imagen.sh`，根据是否含中文文字选择，判断规则见 `references/image-base.md`）。

生成后对照以下检查项，任一不过则自描述问题并提议调整方向，不静默交付：

| 检查项 | 标准 |
|--------|------|
| 留白 | 目测主体以外留白≥画面 30% |
| 主色数量 | 画面主导颜色 ≤ 2（不含黑白灰） |
| 文字可读性 | 标题在缩略图（约 300px 宽）下仍可辨认 |
| 构图完整 | 主体未被裁切，无重要元素贴近边缘 |
| 与方向吻合 | 生成结果的情绪基调与 Step 1 选定方向一致 |

**检查不过的处理方式**：

```
# Bad — 静默重试
直接重新生成，不告知用户

# Good — 结构化反馈
"留白不足（目测约 15%），主体占比过大。建议：将主标题上移，
产品图缩小至画面 50%，重新生成。是否确认？"
```

---

### Step 4：交付物

输出以下内容，不多不少：

1. **最终图像文件**（绝对路径）
2. **参数摘要**（Step 2 填写的参数，一张表，方便下次迭代时复用）
3. **调整入口**：列出最可能被要求修改的 2–3 个维度及对应的参数修改点，方便用户直接说"把主色换成 X"而不用重走全流程

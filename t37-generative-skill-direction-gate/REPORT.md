# t37 — 生成型 skill「先锁方向，再昂贵生成」AB 测试

**日期**：2026-06-26
**来源**：Zara Zhang frontend-slides walkthrough（youtube 372Iksaz8b0，22k★，对话"我们能学到什么"）
**测什么**：把她"内建四问 + 三封面预览闸"的手法提炼成一条候选模式（拟作 skill-design-patterns.md 模式 13），验证嫁接进 `~/.claude/references/skill-design-patterns.md` 是否真有增益（B>A 且 dominant 才采纳，否则回滚 + 记 rejected buffer）。

## 候选模式（注入内容）

「生成型 skill 先锁方向，再昂贵生成」——两道前置闸：
- **闸 1**：生成前用固定清单问题（用途/篇幅/受众/密度）榨取用户意图。
- **闸 2**：昂贵 build 前先出廉价方向样本（3 个封面/骨架），用户选定再 build 全量。
- 跳过条件：确定性 skill / 单步廉价生成 / 用户已给死 spec。

完整注入文本见 `prompts/injection.md`。

## 实验设计（沿用 t16 范式）

- 2 场景 × 2 变体 = 4 输出。A = 基线（读现有 skill-design-patterns.md 全文）/ B = 基线 + 注入。
- 生成：4 个隔离 `general-purpose` 子代理（Sonnet，self-contained，不继承主会话的 Zara 分析，防污染基线）。
- 评分：每场景 2 个独立盲评委（Sonnet），匿名甲/乙 + 位置每场景翻转（S1 甲=A乙=B / S2 甲=B乙=A），5 维各 10 分（满分 50），取两评委均值。

| 场景 | 任务 | 生成型类别 |
|------|------|-----------|
| S1 | 多页 HTML 幻灯片 skill 的核心工作流 | 文本+视觉混合 |
| S2 | 品牌主视觉海报 KV skill 的核心工作流 | 纯视觉 |

## 结果

| 场景 | A 均分 | B 均分 | 净差 | 胜者 |
|------|--------|--------|------|------|
| S1 幻灯片 | 41.0 | 37.5 | **A +3.5** | A（基线） |
| S2 海报 | 37.5 | 42.5 | **B +5.0** | B（注入） |
| **合计** | **78.5** | **80.0** | B +1.5 | 平分（1:1） |

战绩 A 1 胜 / B 1 胜，总分 B 仅领先 1.5——**非 dominant，落在噪声带内**。

## 裁判关键 reasoning

- **S1（基线赢的关键）**：基线 A **自发产出**了"把推断结论写出来让用户确认、不静默跳过"+"确认大纲前不写 HTML"的廉价验证点。注入版 B 的「固定四问」在 prompt 已含充分线索时被判**仪式冗余**，且 B 缺"≤5 页跳过闸 2"这类自由度匹配条款。两评委一致在「自由度匹配」维度给 B 扣分（7 和 5）。
- **S2（注入赢的关键）**：纯视觉场景下，注入 B 的"3 个封面方向廉价预览"比基线 A 的"参数确认 + 偏市场调研的四问"更贴视觉决策、更省额度。但 A 输的部分一半是 A 自身弱点（多加一道参数确认轮次），不纯是 B 的强项。

## 诊断：为什么是 REJECT

与 **t16 #2 同一失败模式**——配置已自带等效覆盖，显式注入反成堆料：

1. **基线自产**：S1 直接证明，现有 `skill-design-patterns.md` 模式 10（Freedom Matching）+ 全局「Assumptions 前置」文化，已让基线对生成型 skill 自发写出"先锁方向 + 廉价确认"。不需要显式模式 13。
2. **固定四问过度触发**：注入的「闸 1 固定清单」违反模式 10 自由度匹配——把本可由 agent 按线索判断的意图榨取，硬写成每次必问，prompt 信息已足时即仪式化。两评委独立点名扣分。
3. **唯一真信号窄且已被覆盖**：闸 2「廉价视觉预览」只在纯视觉场景（S2）清晰加分。但封面/海报方向选择在配置里已有 `references/image-base.md` 决策门 + `reference_x_article_cover_prompts`（6 套框架）覆盖方向锁定，不缺这条通用模式。

## 决策

- ❌ **REJECT**：不并入 `skill-design-patterns.md`。+1.5 平分不过 dominant 闸；基线自产 + 固定四问过度触发，加即堆料。
- 记入 rejected buffer：`feedback_skill_pattern_rejected` 系（与 t16 #2 同模式：先验证后采纳，配置已覆盖的不加）。
- 保留的认知（非配置改动）：生成型 skill 的"廉价预览闸"在**纯视觉**输出上有真价值，但该价值已由 image-base 决策门 + 封面框架承接，不需上升为通用 skill-design 模式。

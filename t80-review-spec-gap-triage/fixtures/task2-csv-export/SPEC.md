# 需求：后台「订单导出」

运营在管理后台按日期范围把订单导出成 CSV，在 Excel 里打开核对。

## 功能点
1. 输入开始日期、结束日期（两端都含当天），导出该范围内创建的订单。
2. 只导出已支付和已发货的订单，已取消的不导出。
3. 列：订单号、用户手机号、金额（元，保留两位小数）、状态、创建时间。
4. 手机号中间四位打星，例如 138****1234。
5. 文件名 orders_<开始日期>_<结束日期>.csv。

## 数据
订单对象字段：id、phone、amountCents（分）、status（pending / paid / shipped / cancelled）、createdAt（Date）。

# t82 — 常驻配置整体瘦身（整体 vs 整体）

2026-09-13。判据预注册在 `CRITERIA.md`，删减台账在 `CUTLOG.md`。

## 为什么这轮不是普通单条 AB

两家官方同月给出同向结论（OpenAI `Rethinking skills and prompts for GPT-6 Astra` / Anthropic Thariq「Claude 5 删 80% 系统提示词无损失」）：模型变强后，为弱模型堆的指令变成负担。

这个命题**单条 AB 结构上测不出来**——每条单规则 AB 都是边际测试（有这条 vs 没这条），而"总量干扰"是涌现效应。所以本轮第一次测整体配置 vs 整体配置。

## 设置

- 两臂：**A = base**（9 个常驻文件全文，75,352 字符）／ **B = slim**（22,166 字符，−70.6%）
- D1 溯源元信息剥离（AB 编号、margin 注释、日期标记）在两臂之前执行，是**共同起点**，不计入本轮 delta。原始 78,643 → 75,352，确定性收益 −4.2%，不需要 AB 证明
- 注入方式：`claude -p --safe-mode --model opus --append-system-prompt "$(cat arm)"`。`--safe-mode` 关掉真实 CLAUDE.md / skills / hooks / MCP，两臂唯一变量是注入的配置文本
- 任务：HELDOUT v1 三任务（H1 写作 / H2 代码 / H3 判断），只喂任务文本
- cwd 为中性临时目录（`/tmp/wk-N`），不含 t 编号或任何评测线索
- 评分：可数维度确定性先跑；主观维度**单篇独立盲评**（每份单独打绝对分，不并排——`feedback_ab_pairwise_slot_bias`），judge 同样 `--safe-mode`

## 判定

预注册规则：「B 不输 → 瘦身无损失，按 slim 入配」。

**B 没输。** 盲评 2 胜 1 负，合计 +4.2%；两个确定性硬闸（H1 字数上限、H2 测试全过）都是 slim 赢。H3 的 −8.3% 在 ±12% 噪声基线内。

诚实的读法是**「砍掉 70.6% 后测不出损失」，不是「砍完更好」**——+4.2% 合计差同样在噪声内。但这轮的成本侧不对称：省下的 53,186 字符是每次 `/clear` 重付一次的固定开销，不是零成本条款。既往「删完更好才删」的 bar 是为零成本单条设的，不适用于本轮。

## 值得单独记的观察

**base 臂带着完整 TDD + Verification 规则，却交付了一份自己测不过的测试。** 失败点是 `test_extension_of["weird." → "(none)"]`，注释里写着 `splitext -> ('weird.', '')` ——它假设了标准库行为、没跑、实现返回的是 `"."`。slim 臂没有那些规则展开，27/27 自洽。

这正是官方文章的主张在本地的一次复现：**指令密度不等于遵守率**。两臂都没能真跑 pytest（环境无 pytest + 权限提示被自动拒绝），所以这不是"base 违反了规则"，是"更多规则没带来更强的自我一致性"。

**slim 臂的 H3 全文用半角逗号**（42 处），base 全角。两臂配置都没有标点规则，归为不可归因的 run 级噪声，但它是产物里真实可见的质量缺陷，记在此供下轮观察是否复现。

## 局限

1. **n=1 / cell，3 个任务。** 合计差在噪声内，本轮只能支持"无可测损失"这一个结论，支持不了"更好"。
2. **最大的一刀没被测到。** skill-tiers.md + skill-chains.md 砍掉 89%（19,053 → 2,090），而 HELDOUT 三任务全不涉及 skill 路由。这块的真实代价本轮为零证据。入配前应单独补一组 skill 路由任务，或先只入配其余部分。
3. **D1 残留。** base 臂仍有 10 行提及 AB/KEEP/margin 的正文（它们本身是业务规则，如 Verification 条款、AB 防污染条款），两臂对称，未剔除。
4. **judge 是单模型单次。** 未做 judge 交叉。

MCP 解决「Claude 够不着」：Figma、内网数据库、要 OAuth 的 SaaS。代价也实在：server 常驻，schema 全程吃 context，中途加一个，前面缓存全作废。

Skills 解决「Claude 够得着，但不知道你要怎么弄」：团队发布流程、周报格式、每次都得交代三遍的规矩。就是个 md 文件夹，不命中不加载，几乎白嫖。

最常见的浪费是拿 MCP 包 CLI。gh、psql 本来就能跑，套一层 server 换来常驻 schema 和一个会崩的进程。

拿不到的东西给 MCP，不懂的规矩给 Skills。

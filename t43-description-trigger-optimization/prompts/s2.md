# 场景 S2 — 给一个新 skill 写并优化 description

我新写了一个 skill 叫 `changelog-gen`：读取一个 git 仓库最近的 commit 历史，按 Keep-a-Changelog 规范生成结构化的 CHANGELOG 片段（Added / Changed / Fixed / Removed 分类），支持指定版本区间。

请给它写一个 description（frontmatter 用），并**把这个 description 优化到触发准确**——既要在用户真正需要时可靠触发，又不能在相邻但不该它管的任务（比如"帮我写个 commit message"、"总结这个 PR 干了啥"、"生成 release notes 发到邮件"）上误触发。

请交付：最终 description + 你为确保触发准确所做的完整过程。

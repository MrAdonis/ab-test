# 场景 S1 — 修一个触发混乱的 skill description

我有个 skill 叫 `xiaohongshu`，当前 description 是：

> 小红书（XHS）账号自动化/批量运营的平台风控、频控、合规与拟人化调度规范。做小红书发帖/评论/私信/关注/投流的自动化或批量脚本、设计账号状态机、排查封号限流时用。

它现在触发混乱，两个方向都出错：
- **误触发**：用户只是想**抓取小红书公开内容 / 读某篇笔记**（这类该走 `rules/routing.md` 四层路由，不是这个 skill），它却常常触发。
- **漏触发**：用户想要**账号被限流后怎么恢复 / 批量关注的安全频率**这类风控建议时，它有时不触发。

请给我优化后的 description，并**说明你用什么方法确认它真的改好了**（不是凭感觉说"这样更清楚了"）。

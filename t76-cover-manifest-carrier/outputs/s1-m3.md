# 编辑隐喻装置风 封面 prompt

你是顶级封面艺术总监、编辑视觉设计师、字体排印设计师和生图 prompt 导演。

Create one single X 文章封面 cover image, aspect ratio 16:9.

本封面必须使用选定视觉风格：编辑隐喻装置风（Editorial Metaphor Device）/ editorial-metaphor-device。该风格不是装饰滤镜——标题、主体、背景、隐喻、质感这五个视觉决策必须全部通过这个风格的视觉语言实现：暖白纸底、四色封闭配色、四类材质白名单、单一核心动作装置。

## Input（只用派生字段）

- 标题层级：
  - 主视觉标题（本风格仅一个标题层，无 A/B 拆分）：别再给 AI 加提示词了，先把输入整理干净
  - 副标题/小字层：无（本风格无 C 层文字，不生成）
- 平台：X 文章封面　比例：16:9　语言：简体中文　用途：长文封面
- 载体：screen_cover（屏幕原生封面，没有物理载体，边缘即画布边缘；必须出现满幅出血构图、一个在 feed 缩略尺寸就成立的焦点、标题层级一眼分主次）
- 画面焦点（只有一个）：玻璃梳状装置与金属杆交汇处——凌乱交叉转为精确平行的那个转折点
- 画面文字恰好是这 19 个字符，不多不少（"AI"是两个拉丁字母，前后保留正常排版间距但不计入字符数；逗号计 1 个字符）：别再给 AI 加提示词了，先把输入整理干净
- 摘要：真正卡住 AI agent 的不是提示词不够多，而是输入本身自相矛盾、说法不一；把输入整理成固定结构后，同样的模型和提示词产出立刻更稳定。
- 视觉主体：一束石墨黑哑光金属杆穿过一块磨砂半透明墨绿玻璃梳状装置——入口端凌乱交叉纠缠，出口端精确平行排列
- 受众：做 AI 工程和内容自动化的从业者　情绪：冷静、克制、有判断力，不做营销号式煽动
- 视觉隐喻：对齐——把互相打架的输入校准成同一套整齐的结构
- 禁用元素：见下方通用负面约束与风格专属禁用项，用户本次未额外指定禁用元素

## 内容理解

理解素材后再构图，但不在图里输出任何分析、不出现文章原文、不出现"整理输入""提示词"这类文字说明或图标标签——只用上面派生字段构图。

封面必须传达：
1. 第一眼知道有一件"从混乱到有序"的事正在发生。
2. 第二眼看到这件事的具体机制——杂乱的杆束正在被玻璃装置梳理、校准成平行排列。
3. 看得出这属于编辑隐喻装置风，而不是通用封面模板：暖白纸底、克制配色、画廊雕塑感。

## 封面目标

生成一张**有编辑意图的封面**，不是通用插画、不是产品渲染图。标题必须完整、准确、逐字可读；本风格标题不拆分层级，一次性完整呈现。

## 装置构造细节（把标题转译成抽象装置）

核心动作：**对齐**——消除偏差、把不统一的东西校准成同一套标准。

装置具体构造：
- 一束哑光石墨黑金属杆，杆的一端（画面右侧靠内，装置区域的入口）以不规则角度交叉纠缠在一起，杆与杆之间有明显的相互挤压、越过、卡住的接触点——这一端要让人读出"混乱、互相冲突"。
- 这束杂乱的杆穿过一块磨砂半透明墨绿玻璃构件（形态是一个带竖向齿槽的梳状/栅格状结构，**不得画成一块水平搁板或平台**，避免被读成桌子、茶几或展台——玻璃构件必须以竖直或斜置的姿态"卡住"杆束，像一把正在梳理线束的梳子，而不是一张杆束搁在上面的桌面）。
- 穿过玻璃梳状构件之后，金属杆在出口端变为精确平行、等间距排列，边缘齐整——这一端要让人读出"已经理顺、标准统一"。
- **量化体积差**：入口端凌乱交叉的杆束视觉体积（含杆与杆之间的重叠、纠缠所占空间）约为出口端平行整齐杆束体积的 1.6-1.8 倍——用体积差替代任何关于宽度倍数的构型约束，让"处理掉的混乱"在视觉上明显大于"剩下的秩序"。
- **可见物理证据**（至少两项同时满足）：入口端杆与杆的交叉处有轻微形变或挤压痕迹；入口端与出口端杆的角度/间距形成清晰对比（未处理 vs 已处理并置在同一画面）；玻璃梳状构件与杆接触的齿槽处留有正在收拢、尚未完全闭合的间隙，暗示这个"对齐"动作仍在发生，不是静止摆拍。
- 玻璃构件本身呈磨砂半透明墨绿色，边缘可见柔和自然阴影投在暖白背景上，不要棚拍高光，不要边缘发光。

**转译红线**：不要把这个装置画成任何图标、说明书插画或字面场景（例如不要画成"漏斗""筛子""排序算法可视化"这类直白比喻）；要做成一个有材质、有结构、有动作的抽象小型装置，观众先感到"有件事正在被理顺"，再回头对上标题。

## 风格应用（editorial-metaphor-device）

- 风格锚点（不可妥协）：暖白/米白纸质背景 + 大量留白，安静精确如画廊里的编辑雕塑；配色仅限暖白、石墨黑、炭灰、低饱和半透明墨绿（四色封闭，不加第五色）；材质仅限哑光石墨金属、精密黑色模块、磨砂半透明绿玻璃、柔和自然阴影；标题转译成一个有材质有结构的抽象小型装置，由单一核心动作（对齐）构成；现代瑞士平面设计 + 克制的科技杂志感，非营销物料。
- 封面形状适配（16:9 横向画幅）：标题在画面左侧 50%-55% 区域内排满；对齐装置在右侧 40%-45% 区域，单一视觉中心，不堆砌第二个装置或多余道具；本次不加入人物——人物会让"输入整理"这个抽象主题显得多余，直接省略。
- 必须保留：四色配色与四类材质白名单不得扩充；抽象装置必须由"对齐"这个核心动作构成，不得画成图标/插画说明书/字面场景；动作必须有可见物理证据（形变/位移差/状态并置/正在闭合的间隙），纯悬浮静置不合格；标题逐字准确、不加原标题没有的标点，仅"干净"这一个词用低饱和墨绿强调，标题其余每一个字都必须是深石墨色；标题在其分区内排满（横版汉字字高约为画面高度的 10%-14%，标题文字块横向撑满其分区宽度的 80% 以上，留白不靠缩小标题挤出来）；除标题外不出现任何可读文字、Logo、水印、副标题、边框、装饰小字；大面积留白与单一视觉中心。
- 应用到封面时禁止：赛博朋克、霓虹、蓝紫渐变、科幻城市、夸张光效；机器人、AI 大脑、芯片、复杂仪表盘、满屏 UI；卡通、家居风、廉价 3D、贴图感塑料质感；副标题、角标、栏目标签、英文装饰小字（本风格无 C 层文字）；扩充配色或材质白名单，尤其是加蓝色、加金属高光、加渐变背景；把主题直译成实物图标或场景插画。

## 通用负面约束（所有风格叠加）

- PPT 封面感、课程封面感、通用信息图模板感、电商广告感
- 标题错字、标题缺失、标题被裁切到不可辨认、标题被视觉元素严重遮挡
- 与主题无关的装饰堆叠
- 多方案网格、联系表（contact sheet）、多选一构图、解释性文字
- mockup 摄影感：纸张投影、翘边、透视变形、桌面或墙面环境、手持展示
- 设备外框（手机/笔记本/平板/浏览器窗口/UI 状态栏）、画中画取景框、内圈白边、相框
- 本次载体（screen_cover）禁止信号：纸张质感边缘/投影/翘边；设备边框；「海报贴在墙上」的环境语境；印刷工艺信号（裁切线、套印色标、出血标记）

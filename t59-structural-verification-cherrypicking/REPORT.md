# t59 — 结构性核查（反选择性偏差）加进 review-base.md

**结论：QUALIFIED KEEP（弱正，margin 随选择偏差纯度上升）**

## 来源
读 @sujingshen「AI 时代的知识编排」系列 #05 信息核查，唯一比现有 review-base.md 更锋利的一点：现有 P0 逐条查断言真伪，缺一条"断言的**选择**是否代表全貌"的轴（反 cherry-picking）。t59 测这条轴加进去是否有增量。

## 设置
- baseline 模型 = Sonnet 5（两变体同模型，隔离规则效果）
- A = 现行 review-base.md（P0-P3）
- B = A + 「结构性核查（P0 附加轴：反选择性偏差）」三问段
- 两篇待审文章都是虚构数码测评（无客户名/无真实品牌），带选择偏差缺陷
- prompt 卫生：候选 prompt 无 t 编号/AB/baseline/cherry-picking 字样，任务写成真实审稿请求

## 两轮结果

| | Round 1（带内部破绽的稿）| Round 2（纯选择偏差、无自相矛盾的稿）|
|---|---|---|
| A baseline | ⚠️ 抓到 3 处结构问题，挂在 以偏概全/归属缺失/因果不成立 下 | ⚠️ 抓到结论泛化，但对"漏了哪些不利维度"只给笼统一句 |
| B with rule | ⚠️ 多抓 1 处（屏幕无对照却算"第一"）+ 手法点得更准 | ❌ 用领域知识**具体枚举**被省略的不利维度 + 识别"零缺点=选择性信号"，判罚更重 |
| 差距 | 薄（baseline 用内部破绽就能抓到大部分）| 明显（baseline 缺具体点名能力）|

## 判读

**Round 1 接近平手**——文章自曝多核弱、缺 T本数据，baseline 用普通 P0（以偏概全/归属缺失）就抓到了核心结构问题，两者同判 ⚠️。这复现了 t31/t47/t57 的老剧本：Sonnet 5 baseline 自己就会做结构性核查。

**Round 2 拉开真实 margin**——当偏差是"纯选择"（每条断言真且完整、无自相矛盾、要靠世界知识才能发现漏了什么）时，baseline 只会笼统说"还涉及其他维度"，而 B 主动枚举了具体被省略的不利维度（广角/微距/色彩/长焦倍数 vs 潜望式/续航发热/机身），并识别"通篇零缺点=选择性呈现的信号"，判罚从 ⚠️ 升到 ❌。这是可复现的行为增量，不只是语气差异——对事实密集审稿，"点名具体缺失的反面证据"才是可操作产出。

## 结论与边界

规则的价值 = 把审稿人从"被动接受文内证据（每条查过就通过）"推到"主动质问代表性、用世界知识枚举被省略的不利面"。这正是现行逐条 P0 不显式覆盖的失败模式。margin 随文章偏差纯度上升——越是"全维度领先/闭眼选"式软文（内部无破绽），规则越值钱。

诚实标注：n=1/条件、单评委（我）、两任务。不是强 KEEP，是弱正。按 少而准，规则体量小（一段三问），可接受。

# 审核方法

## P0-P3 优先级体系

| 级别 | 含义 | 标准 |
|------|------|------|
| P0 | 事实与数字 | 错了就是事故：数字不准、因果不成立、归属缺失、时效错误 |
| P1 | AI 套话与模板感 | 逐句零容忍：禁词、结构性套路、模板化开头/收尾 |
| P2 | 结构与格式 | 钩子是否有力、信息密度、字数范围、格式合规 |
| P3 | 语感与节奏 | 连续同句式、长短句失衡、书面腔过重 |

## 结构性核查（P0 附加轴：反选择性偏差）

P0 逐条查断言真伪，本轴查断言的**选择**是否代表全貌——每条数字都真、但挑着说也能骗人。触发：文章用一组事实/数字/案例支撑一个总体判断（对比、排名、趋势、"最X"、"全面领先"、"证明了Y"）。

三问：
1. **抽样代表性**：列举的有利证据是否刻意漏掉了同样存在的反例？换一批同样真实的指标会不会得出相反结论？
2. **结论过载**：每条断言都成立，但合起来撑得起那个总体判断吗？（真前提 + 无效推理 = 真数字假结论）
3. **缺口点名**：把"漏掉了什么会动摇结论的证据"当 P0 问题写出来，不能因为"每个数字都对"就整体放行。

判据：每条数字都 ✅ 但总体结论仍可疑时，问题在选择不在真伪——照 P0 报，并写明被弱化/省略的反面证据。

跳过：不下总体判断的纯罗列 / how-to / 单条事实陈述。

- 引用原句 → 问题 → 修改建议

## 评级标准
- ✅：P0 全部通过，P1 最多 1 处轻微问题
- ⚠️：有 P0 问题（含结构性选择偏差），或 P1 有 2+ 处
- ❌：P0 有严重事实/数字错误或结论被选择性证据误导，或 P1 问题密集（5+ 处）

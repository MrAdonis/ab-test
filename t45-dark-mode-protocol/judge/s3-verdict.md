# 盲评：浮屿书店编辑风 Landing（Design1 vs Design2）

评审对象：`s3-design1.html` / `s3-design2.html`（来源匿名，仅按质量打分）

---

## Design 1

### 1. 编辑风完成度与纸面感（50%）— 8.5/10
- 报头与页脚均用 `border: 3px double var(--ink)` 双线规——这是报刊/古籍版式的经典惯例，出现两次形成呼应闭环。
- 店主手记用真正的 `column-count: 2` 杂志分栏 + `::first-letter` 首字下沉（58px，暖红色），是印刷排版的核心技法而非装饰。
- 页脚右侧一枚旋转 -6° 的圆形朱红印章（"浮屿 藏书之印"），是全篇最具"实物印刷品"说服力的细节，让页面读起来像有人真的盖了章。
- 全程零 JS，只有一次性 CSS `pageIn` 淡入（页面整体一次显影，接近"翻开一本书"的静态感），不存在任何会打破"这是一张纸"错觉的 Web 交互。
- 唯一的现代 Web 痕迹是 `.book:hover` 背景色变化——极轻微，可视为可用性增强，不构成破坏。
- 瑕疵：定义了 `@font-face 'NotoSerifFallback'` 但全篇 `font-family` 栈从未引用它，是死代码。

### 2. 整体设计品质（30%）— 8.0/10
- 色彩极克制：暖纸色 + 暖墨色 + 单一朱红强调色，贯穿页码、书号、标签、印章，纪律性强。
- 书单用 num/content 两列 grid + 顶部 hairline 分隔，没有落入卡片网格套路。
- 整体气质偏"旧式期刊/古籍"，温暖但略偏保守，两栏文本排布是标准杂志排法，惊喜感略弱于对方的非对称版式。

### 3. 代码质量（20%）— 7.5/10
- 结构清晰、CSS 变量精简、响应式覆盖全（栏数收缩、grid 转单列、footer 转纵向）。
- 语义化有欠缺：书单用 `div` 而非 `ul/li`；`aria-label` 与可见标题内容重复，不如 `aria-labelledby` 精确；死代码扣分。

**加权总分：0.5×8.5 + 0.3×8.0 + 0.2×7.5 = 8.15**

---

## Design 2

### 1. 编辑风完成度与纸面感（50%）— 7.5/10
- 引入 Playfair Display（拉丁衬线）搭配 Noto Serif SC 做数字/首字视觉对比，是更"专业编辑设计"的字体配对手法，比单一 CJK 衬线更有层次。
- 手记区用 1.5fr/1fr 非对称网格，右侧做了独立的 pull-quote（摘句强调），这是真实杂志排版的常见手法，比单纯两栏纯文本更有设计感。
- 店铺信息用 `dl/dt/dd` 呈现营业时间，`〔...〕` 括注猫的细节，印刷排版惯例运用到位。
- 加了 `@media print` 专门处理实际打印场景（去阴影、去噪点、铺满页），是对"纸面"主题更彻底的呼应，design1 未做此项。
- 硬伤：全篇用 `IntersectionObserver` 做逐 section 滚动淡入（opacity 0→1 + translateY），这是典型的"网页落地页"交互模式，与"这是一张印刷品"的错觉直接冲突——真正的纸面不会随滚动逐段显影。虽然遵守了 `prefers-reduced-motion`，但默认体验下这是本题最大的气质减分项。
- 单线 masthead 规则（非双线），克制感不如 design1 的双线更具"报刊感"信号强度。

### 2. 整体设计品质（30%）— 8.3/10
- 有系统化间距变量（`--sp-1` 到 `--sp-24`），工程纪律更强。
- 手记区非对称网格 + pull-quote 让版式层次比 design1 的对称两栏更丰富，更接近真实杂志跨页设计。
- 冷灰蓝强调色（#2f4459）克制、现代，书单同样避免卡片网格套路（顶部 hairline 分隔）。
- 冷色调配暖纸色的对比比 design1 的暖色系更有"现代独立书店"气质，但也因此比 design1 略少一分"老纸"的怀旧温度感。

### 3. 代码质量（20%）— 7.8/10
- 语义化更好：`ul/li` 列表、`dl/dt/dd` 时间表、`aria-labelledby` 绑定真实标题 id，均比 design1 更规范。
- 但引入的滚动揭示 JS 有真实健壮性风险：脚本先把目标元素设为 `opacity:0`，若 JS 被阻塞或报错，`IntersectionObserver` 不会触发，内容会永久不可见——这是没有 no-JS 兜底的渐进增强反模式,对单文件静态页面而言是不必要的复杂度和风险。
- 外部 Google Fonts 依赖（需联网），design1 完全本地系统字体栈，更适合"单文件离线可用"的场景设定。

**加权总分：0.5×7.5 + 0.3×8.3 + 0.2×7.8 = 7.80**

---

## 结论

**胜者：Design 1（8.15 vs 7.80）**

核心差距：Design1 全程零 JS + 双线规 + 实体印章，把"纸面感"落到结构性惯例上，说服力更强；Design2 虽然字体配对、pull-quote、语义化代码更讲究，但滚动触发的 JS 淡入是与"印刷品"气质直接冲突的网页化交互，且存在无 JS 兜底时内容永久隐藏的健壮性风险，在最高权重的纸面感维度上被明显拉低。

# t45 场景定义

## S1 — 靶场:显式要求双模式(中文 B2B 产品 UI)

**Brief**:为团队协作 SaaS「协流」做项目仪表盘页面(单文件 HTML,含内联 CSS/JS)。内容:顶部导航(logo/项目切换/搜索/头像)、左侧边栏(项目列表 5 项)、主区域为「本周概览」:4 个统计卡(进行中任务/已完成/逾期/成员活跃度)、一个任务列表表格(8 行:任务名/负责人/截止日/状态标签)、一个简单的每日完成数条形图(纯 CSS 即可)。**要求支持亮色和暗色双模式**,带切换入口。中文界面。

**测什么**:token 策略统一性、暗色对比度独立校验、层级 parity、无纯黑纯白、主题锁(section 不反转)。

## S2 — 靶场:不提暗色的消费级 landing(默认双模式自发性)

**Brief**:为消费级阅读 App「夜航」做官网 landing(单文件 HTML)。夜航主打「睡前 30 分钟深度阅读」,目标用户是都市失眠年轻人。内容:hero(标语+下载按钮)、3 个核心功能介绍(护眼排版/离线书库/阅读时长仪式感)、用户评价 2-3 条、订阅价格(免费版/Pro ¥18/月)、footer。中文。**brief 不提任何模式/主题要求**。

**测什么**:B 是否自发按双模式设计(协议「默认双模式」条款);若双方都做或都不做,比实现质量(token/parity/纯黑)。

## S3 — 控制组:仿印刷编辑风(协议应豁免,测泄漏)

**Brief**:为独立书店「浮屿书店」做一页编辑风 landing(单文件 HTML)。纸感、仿印刷杂志版式:大标题衬线、栏式排版、店主手记一段、本月选书 4 本(书名/作者/一句推荐)、店址与开放时间。要求有明确的「纸面感」,像一页印刷品。中文。

**测什么**:B 的暗色协议是否泄漏噪音——协议明文豁免仿印刷编辑风,B 不应硬塞暗色 toggle/双模式而破坏纸感;编辑风完成度不应低于 A。

## 评审维度(judge 用)

- S1:暗色实现质量 45%(token 策略统一/两模式对比度/层级 parity/无纯黑纯白/主题锁) + 整体设计品质 35% + 代码质量 20%
- S2:模式策略与实现 40%(是否双模式、若单模式是否合理、实现质量) + 整体设计品质 40% + 代码质量 20%
- S3:编辑风完成度与纸面感 50% + 整体设计品质 30% + 代码质量 20%(暗色元素若出现且破坏纸感应扣分)
